# Password & Account Management

## Password Reset Procedure

**Self-Service Reset:**
1. Go to https://password.company.com
2. Enter your employee email address.
3. Select "Reset via Email" or "Reset via SMS".
4. Follow the link in the email within 15 minutes.
5. New password must meet complexity requirements:
   - Minimum 12 characters
   - At least one uppercase letter
   - At least one number
   - At least one special character

**If self-service fails:**
1. Contact the IT Help Desk at ext. 4357.
2. Provide your employee ID for identity verification.
3. IT will issue a temporary password valid for 24 hours.
4. Change the temporary password immediately on first login.

---

## Account Locked Out

**Steps:**
1. Wait 15 minutes — accounts auto-unlock after lockout period.
2. If urgent, call IT Help Desk at ext. 4357.
3. Do NOT attempt further password entries as this extends the lockout.
4. Check if Caps Lock is enabled before retrying.

**Common reasons for lockout:**
- Saved wrong password in browser or mobile device
- Old credentials in scheduled tasks or mapped drives
- Multiple failed VPN attempts

---

## Multi-Factor Authentication (MFA)

**Setup:**
1. Install Microsoft Authenticator on your mobile device.
2. Go to https://mfa.company.com/setup
3. Scan the QR code with the Authenticator app.
4. Enter the 6-digit code to confirm setup.

**If MFA token not working:**
1. Ensure time on your phone is synced (Settings → Date & Time → Automatic).
2. Try the backup code provided during setup.
3. Contact IT if you've lost access to your authentication device.

---

## New Employee Account Setup

1. IT will provision the account within 24 hours of start date.
2. Initial login credentials sent to personal email.
3. Required first-day steps:
   - Change password
   - Setup MFA
   - Connect to corporate VPN
   - Map network drives per department guide
