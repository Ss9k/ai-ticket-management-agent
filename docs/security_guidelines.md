# Security Guidelines & Incident Response

## Suspected Phishing Email

**Indicators:**
- Unexpected sender or spoofed domain
- Urgent language requesting credentials or payment
- Suspicious links (hover to preview URL before clicking)
- Unexpected attachments

**Steps:**
1. Do NOT click any links or open attachments.
2. Do NOT reply to the email.
3. Report via: Outlook → Report Message → Phishing.
4. Forward email as attachment to: security@company.com
5. Delete the email from your inbox.
6. If you clicked a link, immediately:
   - Disconnect from network
   - Contact IT Security at ext. 4911 (24/7)

---

## Malware / Ransomware Suspected

**CRITICAL — Act Immediately:**
1. Disconnect the computer from the network (unplug cable or disable WiFi).
2. Do NOT turn off the computer.
3. Call IT Security immediately: ext. 4911.
4. Do NOT attempt to clean the infection yourself.
5. Preserve the state of the machine for forensic analysis.

---

## Unauthorized Access Detected

1. Change your password immediately from a different device.
2. Enable MFA if not already active.
3. Report to IT Security: security@company.com
4. Review your account activity in the security portal.
5. IT Security will investigate and provide a timeline.

---

## Data Loss Prevention

**Sensitive Data Handling:**
- Never store sensitive data on personal devices.
- Use company-approved encrypted drives only.
- Do not email sensitive data externally without encryption.
- Use the company DLP tool for secure file transfers.

**Acceptable Use:**
- Company devices are for business use.
- Personal software installation requires IT approval.
- Accessing inappropriate content on company devices is prohibited.

---

## Security Patch Management

- Critical patches: Applied within 24 hours automatically.
- Standard patches: Monthly Patch Tuesday cycle.
- If prompted to restart for updates, do so within 48 hours.
- Report failed update installations to IT.
